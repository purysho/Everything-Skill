# Licensing and Compliance Recommendation

## Recommendation

Describe the project as **source-available**, not open source. The OSI definition requires open-source licences to allow commercial use, so the requested commercial restriction is incompatible with the Open Source Definition. genui{"citation":{"refs":["turn2search2","turn2search3"]}}

Use **PolyForm Noncommercial 1.0.0** as the project licence. Its official text permits noncommercial use, changes, and distribution with required notices, and includes a no-liability provision to the extent allowed by law. genui{"citation":{"ref":"turn3view0"}}

The project should use the official unmodified licence text, with the project’s copyright holder and required notice added exactly as the licence specifies. The repository must not claim that this licence prevents all forks: it requires notices but permits noncommercial distribution of changes. A separate trademark/official-brand policy can prevent impersonation, and commercial use remains subject to a separate commercial licence.

Do not invent a licence or describe the result as OSI-approved. Creative Commons also recommends against using its licences for software. genui{"citation":{"ref":"turn2search4"}}

## Intended permissions

- Personal, educational, research, testing, hobby, and other noncommercial use: permitted.
- Private modifications: permitted with attribution and notices.
- Public modified distributions: permitted under PolyForm Noncommercial with attribution, copyright, licence, provenance, and changed-version notices.
- Commercial use, hosted commercial substitution, resale, paid redistribution, or commercial deployment: separate commercial licence required.
- Trademark, official name, logo, and maintainer identity: reserved separately.

## Compliance baseline

The implementation will use privacy-by-design controls: local/private defaults, data minimisation, purpose limitation, transparency, secure handling, auditability, export/rollback, and user control. GDPR principles include lawfulness/transparency, purpose limitation, data minimisation, accuracy, storage limitation, integrity/confidentiality, and accountability. genui{"citation":{"ref":"turn2search5"}}

"Global compliance" cannot be guaranteed by a code repository alone. Jurisdiction-specific counsel must review the release before it is used as a service or processes personal data at scale.

## Official licence source

Use the official text: https://polyformproject.org/licenses/noncommercial/1.0.0

Do not rewrite, shorten, or combine the PolyForm terms with project-specific restrictions inside the licence file. Put branding and contribution guidance in separate files and have counsel review any additional terms.
